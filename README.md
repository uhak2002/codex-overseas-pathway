# Codex 예약 기능을 활용한 해외대 진학 사업 실행 리포트

## 과제 목적

24년간 축적한 상담 경험을 학생과 학부모가 이해할 수 있는 진학 정보와 유료 서비스로 전환한다. Codex 예약 기능으로 매일 실행할 업무 3개와 콘텐츠 초안, 측정 지표를 생성하고, 대표가 검토·실행한 결과를 다음 업무에 반영하는 운영 방식을 설계한다.

현재 단계는 **1단계: 익명 사례와 진학 경로 지도로 신뢰 확보**다. 최종 목표는 월 매출 **5,702,000원 이상**이며, 달성한 실적이 아닌 사업 목표다.

## Codex 예약 기능을 선택한 이유

- 정해진 시간에 같은 기준으로 실행 리포트를 생성하여 일일 업무 누락을 줄인다.
- 현재 단계와 전일 결과를 바탕으로 오늘의 우선순위를 업무 3개로 좁힌다.
- 상담 경험을 질문 목록·콘텐츠·상품 기획으로 연결하고 같은 양식으로 진행 상황을 비교한다.

예약은 업무 제안과 초안 생성을 담당한다. 대표가 자료의 정확성을 검토하고 실제 게시·판매·상담을 수행한다. 예약이 비공개 상담 기록이나 전일 결과를 자동으로 기억하거나 가져온다고 가정하지 않는다.

## 매일 실행되는 업무

1. 제공된 익명 상담 요약과 전일 보고를 확인하여 현재 단계와 오늘의 목표를 정한다.
2. 우선 업무 3개의 산출물·완료 기준을 정하고, 반복 질문 목록과 콘텐츠 초안 1개를 작성한다.
3. 목표 대비 결과, 미확인 정보, 다음 행동을 측정 지표와 종료 보고 양식에 정리한다.

1단계 첫날의 과제는 상담 기록에서 반복 질문 10개를 선정하는 것이다. 원문이 없으면 예시 질문을 제안하고 실제 빈도 검증을 미완료로 남긴다.

## 실행 시간과 결과 확인 방법

| 항목 | 설정·확인 기준 |
| --- | --- |
| 예약 이름 | 해외대 진학 사업 일일 실행 리포트 |
| 실행 주기 | 매일 오전 9시, 한국 시간(Asia/Seoul, UTC+9) |
| 실행 환경 | 이 저장소에 접근할 수 있는 Codex 환경 |
| 입력 | 아래 전체 프롬프트, 대표가 제공한 익명 상담 요약, 최신 종료 보고 |
| 출력 | 현재 단계·오늘의 목표·업무 3개·콘텐츠 초안·측정 지표·종료 보고 |

**위 시간은 과제용 제안 설정이며, 이 저장소의 문서 작성만으로 예약이 생성되지는 않는다. 실제 예약 등록 및 실행 이력은 이 과제 문서에서 확인되지 않았다.**

예약 등록 시 [전체 프롬프트](automation-prompt.md)의 코드 블록을 입력하고 시간대와 실행 환경을 확인한다. 실행 후 Codex의 해당 예약 작업과 연결된 실행 대화에서 실행 상태와 결과를 확인한다. 실패하거나 입력이 누락된 경우 원인을 기록하고 수정 후 재실행한다.

대표는 결과를 검토한 뒤 종료 보고를 별도로 보관하고 다음 실행에 제공한다. 실행 결과를 GitHub에 보관할 때는 개인정보를 제거하고 예시와 실제 기록을 구분하여 커밋한다. 실제 실행을 제출 증빙으로 사용할 경우 실행 일시·상태·결과 링크를 추가한다.
